# Litera / Workshare Compare — Behavior & Gap Ledger

Ground-truth reference for the parity torture battery. No live Litera access;
behaviors are researched. Confidence: H = documented (cited); M = strong
inference; L = best guess. "SorkWhare status" is filled/confirmed during the
battery run (Task 7).

Note: some `support.litera.com` pages render as an empty JavaScript shell on
direct fetch, so their content below was verified via search-result snippets
rather than a rendered page fetch.

## Detection behaviors (C1–C8)

| id | Litera behavior | Confidence | Source | SorkWhare status |
|----|-----------------|-----------|--------|------------------|
| C1 | Character/word substitutions shown inline as strike+insert within the paragraph — deleted text struck through in one color, inserted text (double-)underlined in another | H | https://workshare.my.salesforce-sites.com/knowledgebase/servlet/fileField?id=0BE60000000boLI (Workshare Compare Server Rendering Set Guide: "inserted text is shown in blue with double underline and deleted text is shown in red with strikethrough") | TBD (Task 7) |
| C2 | Whitespace-only differences (spacing, line breaks) are not surfaced as their own change entries | L | inference | TBD (Task 7) |
| C3 | Numeric/date edits shown as whole-value replacements rather than digit-by-digit diffs | L | inference | TBD (Task 7) |
| C4 | Dense rewrites within a sentence are grouped into a small number of contiguous delete/insert phrases rather than many tiny fragments | L | inference | TBD (Task 7) |
| C5 | Relocated paragraphs/blocks flagged as a distinct "move" change (not delete+insert) | H | https://support.litera.com/article/Enabling-Configuring-Vertical-change-lines-in-Litera-Compare ("Litera Compare identifies insertion, deletion, or move in every document"); https://workshare.my.salesforce-sites.com/knowledgebase/servlet/fileField?id=0BE60000000TU9p (Workshare Compare User Guide: moved-text option shows relocated text as a distinct change rather than as ordinary insert+delete) | TBD (Task 7) |
| C6 | Split/merged paragraphs flagged as a distinct change type separate from delete+insert | L | inference — no vendor documentation found describing a dedicated split/merge category; both products document insertion/deletion/move/formatting as the change taxonomy, with no fourth "split/merge" type mentioned | TBD (Task 7) |
| C7 | Table cell edits diffed within the cell/row rather than treating the whole table as replaced; an "intelligent table comparison" mode isolates text-only cell changes from layout changes | H | https://support.litera.com/article/Comparison-Settings-in-Litera-One-619910 ("With intelligent table comparison selected, Litera Compare focuses on changes to the text within table cells while ignoring layout changes") | TBD (Task 7) |
| C8 | Changes are numbered and navigable, with the ability to jump to a specific change or step through them in order | H | https://support.litera.com/article/Reviewing-comparisons-in-Litera-Compare-for-Word-676506 ("Litera Compare allows you to choose to view any or all changes, scroll or jump to specific changes, or use numbered changes") | TBD (Task 7) |
